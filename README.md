Project Summaries
Task 1: Developer Portfolio

A responsive portfolio with About, Selected Projects, Skills and Contact sections. It showcases Nova Study Planner, a cafe landing page and a personal portfolio, and lists the tools I use: HTML5, CSS3, JavaScript, Bootstrap, Tailwind CSS and WordPress.

Task 2: TaskFlow

A task manager with full CRUD. Tasks can be added with a category (Work, Personal, Study, Health, Other) and a priority (Low, Medium, High), edited with a double-click, completed and deleted. Tasks can be reordered by drag and drop and filtered by status or category. A summary shows total, active, done and overdue tasks with a completion percentage. Everything is saved in the browser with localStorage, so tasks stay after a refresh.

Task 3: WeatherNow

A weather app where you search for a city and see live conditions fetched from a REST API. It has a °C/°F toggle and shows a loading state while data arrives.

How to Run

All three projects are plain HTML, CSS and JavaScript, so nothing needs to be installed.

Clone the repo:
bash
   git clone https://github.com/MinahilAtif/Datheon_Full_Stack_Web_Development_Internship.git
Open the folder of the project you want.
Double-click index.html, or use the VS Code Live Server extension.

Task 3 needs an internet connection, since it calls a weather API.
